4. TASK OVERVIEW
=============================================================================

Task 1: Building the Visual Vocabulary
---------------------------------------
Goal: Create a codebook of visual words from training images

Steps:
1. Extract SIFT features from all training images
2. Collect all SIFT descriptors into one large array
3. Apply K-Means clustering (K=50 or K=100)
4. Save the cluster centers as vocabulary.pkl

Input: Folder with 20+ training images
Output: vocabulary.pkl file
Time: ~20 minutes

Run: python task1_build_vocabulary.py

Task 2: Image Representation
-----------------------------
Goal: Convert images to BoVW histograms

Steps:
1. Load the vocabulary from Task 1
2. Extract SIFT features from test images
3. Map each feature to nearest visual word
4. Create normalized histogram
5. Visualize and compare histograms

Input: vocabulary.pkl, test images
Output: Histogram plots, comparison
Time: ~15 minutes

Run: python task2_image_representation.py

Task 3: Image Classification
-----------------------------
Goal: Classify images using BoVW representations

Steps:
1. Convert all images to BoVW histograms
2. Split into train/test sets (80/20)
3. Train KNN and SVM classifiers
4. Evaluate with accuracy and confusion matrix
5. Compare classifier performance

Input: vocabulary.pkl, organized dataset
Output: Classification results, confusion matrices
Time: ~25 minutes

Run: python task3_classification.py

5. UNDERSTANDING THE CODE
=============================================================================

Key Concepts in the Code:
-------------------------

1. SIFT Feature Extraction:
   - cv2.SIFT_create(): Creates SIFT detector
   - detectAndCompute(): Finds keypoints and descriptors
   - Each descriptor is 128-dimensional vector

2. K-Means Clustering:
   - sklearn.cluster.KMeans()
   - Groups similar descriptors together
   - Cluster centers = visual words

3. Vector Quantization:
   - cdist(): Computes distances between descriptors and vocabulary
   - argmin(): Finds nearest visual word for each descriptor

4. Histogram Creation:
   - np.histogram(): Counts occurrences of each visual word
   - Normalization: Makes histogram sum to 1.0

5. Classification:
   - KNeighborsClassifier: Finds K nearest training samples
   - LinearSVC: Finds optimal separating hyperplane

6. COMMON ERRORS AND SOLUTIONS
=============================================================================

Error: "No module named 'cv2'"
------------------------------
Solution: Install opencv-python
    pip install opencv-python opencv-contrib-python

Error: "SIFT is not available"
------------------------------
Solution: You need opencv-contrib-python
    pip install opencv-contrib-python --upgrade

Error: "No images found in folder"
----------------------------------
Solution: Check your folder path
    - Use absolute path: /home/user/images/training_images
    - Or relative path: ./training_images
    - Verify images have correct extensions (.jpg, .png)

Error: "Vocabulary file not found"
----------------------------------
Solution: Run Task 1 first to create vocabulary.pkl
    python task1_build_vocabulary.py

Error: "No SIFT features extracted"
-----------------------------------
Solution: Your images might be:
    - Too small (use larger images)
    - Too blurry (use clearer images)
    - Too uniform (use images with textures/edges)

Error: "KMeans not converging"
------------------------------
Solution: 
    - Reduce K (number of clusters)
    - Increase max_iter parameter
    - Check that you have enough descriptors

Error: "Low classification accuracy"
------------------------------------
Possible causes:
    - Too few training images (need 20+ per class)
    - Vocabulary size K is too small (try K=100 or K=200)
    - Images are too similar between classes
    - Not enough variety in training data
